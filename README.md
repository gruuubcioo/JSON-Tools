# JSON-Tools

### Live demo
[Json-Tools](https://www.json-tools.me)

**JSON Tools** is a web application designed for developers to perform text operations on JSON structures. It allows users to minify, format (pretty print), filter and compare JSON files for differences.The application is fully containerized with Docker and deployed in Azure, featuring a Spring Boot backend and a React (Vite) frontend served by Nginx.
